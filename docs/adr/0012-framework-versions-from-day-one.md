# Framework Versions exist from day one

Every Requirement belongs to a Framework Version, and every Implementation is tied to one, even though v1 seeds only a single version per Framework. KRITIS-DachG was amended within four months of entering into force, and its thresholds ordinance, minimum requirements (§ 14) and official templates are still to come. Adding versions after Implementations and Evidence exist would mean migrating all of them. A Requirement whose specifics still await an ordinance is marked as Pending Legal Detail rather than left out.

## Consequences

- A new Framework Version never changes existing Implementations in place. Moving a Tenant to a new version is an explicit step that carries status and Evidence across where Requirements correspond.
